# Portfolio — HTML + CSS

Portfolio personal con estética inspirada en GitHub, construido únicamente con HTML semántico y CSS — sin frameworks ni JavaScript.

🔗 **Demo en vivo:** [carlospaskual.github.io/portfolio](https://carlospaskual.github.io/portfolio/)

## Qué incluye

Proyecto realizado para el Máster de programación, cumpliendo estos requisitos técnicos:

- HTML semántico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Variables CSS (`:root`) para colores y reset inicial
- Flexbox para la navegación, badges y formulario
- CSS Grid para la galería de proyectos
- Diseño responsive con media queries
- Tipografía personalizada (Google Fonts — Press Start 2P)

## Estructura

```
index.html      # Estructura semántica completa
styles.css      # Estilos, organizados por sección con comentarios
images/         # Imágenes identificativas de cada proyecto
```

## Stack

HTML5, CSS3 (Flexbox, Grid, variables), Google Fonts.

## Qué aprendí

Construir un layout completo con Flexbox y Grid sin depender de ningún framework, y diseñar un sistema de variables CSS coherente para mantener consistencia visual en toda la página.
